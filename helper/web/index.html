LINE 連接設定 (照著四步做)

第一次使用要完成這四步, AI寶 才能進群組回答問題。一步一步來, 做完一步再做下一步。

步驟一: 用次要帳號登入 LINE

打開核心登入頁, 用手機 LINE 掃畫面上的 QR 碼, 再輸入畫面上的 PIN 碼。一定要用次要帳號登入, 不要用主帳號。

步驟二: 把機器人加入群組, 並把群組加入白名單

先在手機 LINE 把剛登入的次要帳號邀請進要使用 AI寶 的群組。然後回來按「讀取我的群組清單」, 群組會自己列出來, 用點的加入白名單就好, 不用自己找代號。
進階: 手動貼上群組 ID (清單讀不到時才需要)
備用方法: 在核心頁面點進群組的聊天室, 用「複製聊天室 ID」取得 ID 後貼到這裡。
白名單狀態讀取中…
白名單改好之後, 要把 AI寶 完全關閉再重新開啟才會生效; 重開後再繼續步驟三。

步驟三: 取得機器人 Token

Token 是機器人連上核心的鑰匙。打包版直接按「自動產生 Token」, 產生後會自動儲存、自動重新連線, 不用再貼一次。手邊已有 Token 的話, 貼到欄位按「儲存 Token」也可以。
注意: 重新產生 Token 會讓舊 Token 立刻失效; 用「自動產生」會一併把新 Token 存好, 不會弄丟。

步驟四: 確認連線成功

看本頁最上方的「LINE 連線狀態」卡片變成「已連線」就完成了。之後在群組裡打「AI寶, 你的問題?」就會回答。
