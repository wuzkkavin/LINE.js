LINE 連接設定 (照著四步做)

第一次使用照著四步做，AI寶 才能進群組回答問題。

步驟一: 用次要帳號登入 LINE

打開核心登入頁，用手機 LINE 掃 QR 碼、輸入 PIN 碼。一定要用次要帳號登入，不要用主帳號。
如果機器人突然讀不到某位同事的訊息，請先在登入頁登出再重新掃碼登入。

步驟二: 把機器人加入群組, 並把群組加入白名單

先把次要帳號邀請進群組，再按「讀取我的群組清單」，用點的加入白名單就好。
進階: 手動貼上群組 ID (清單讀不到時才需要)
備用方法: 在核心頁面點進群組的聊天室, 用「複製聊天室 ID」取得 ID 後貼到這裡。
白名單狀態讀取中…
白名單改好後要完全關閉再重新開啟才生效。

步驟三: 取得機器人 Token

打包版直接按「自動產生 Token」，產生後會自動儲存並重新連線。
重新產生 Token 會讓舊 Token 立刻失效。

步驟四: 確認連線成功

看最上方的狀態卡變成「已連線」就完成了。
