LINE 連接設定 (照著四步做)

第一次使用要完成這四步, AI寶 才能進群組回答問題。一步一步來, 做完一步再做下一步。

步驟一: 用次要帳號登入 LINE

打開核心登入頁, 用手機 LINE 掃畫面上的 QR 碼, 再輸入畫面上的 PIN 碼。一定要用次要帳號登入, 不要用主帳號。
什麼時候要登出再重新登入? 如果機器人突然讀不到某位同事的訊息 (例如群組有人加入或離開之後), 那是 LINE 換了讀訊息的鑰匙、跟這台電腦對不上。請在核心登入頁先登出、再重新掃 QR 登入, 讓鑰匙重新對齊; 若還是讀不到, 下一步是把機器人移出該群組、再重新邀請它加入 (重新入群會重新分發鑰匙)。重新啟動程式修不好這個問題。

步驟二: 把機器人加入群組, 並把群組加入白名單

先在手機 LINE 把剛登入的次要帳號邀請進要使用 AI寶 的群組。然後回來按「讀取我的群組清單」, 群組會自己列出來, 用點的加入白名單就好, 不用自己找代號。
進階: 手動貼上群組 ID (清單讀不到時才需要)
備用方法: 在核心頁面點進群組的聊天室, 用「複製聊天室 ID」取得 ID 後貼到這裡。
白名單狀態讀取中…
白名單改好之後, 要把 AI寶 完全關閉再重新開啟才會生效; 重開後再繼續步驟三。

步驟三: 取得機器人 Token

Token 是機器人連上核心的鑰匙。打包版直接按「自動產生 Token」, 產生後會自動儲存、自動重新連線, 不用再貼一次。手邊已有 Token 的話, 貼到欄位按「儲存 Token」也可以。
注意: 重新產生 Token 會讓舊 Token 立刻失效; 用「自動產生」會一併把新 Token 存好, 不會弄丟。

步驟四: 確認連線成功

看本頁最上方的「LINE 連線狀態」卡片變成「已連線」就完成了。之後在群組裡打「AI寶, 你的問題?」就會回答。

名字由你自訂: 同事在群組打到這個名字, 我就會回應。改名不用改程式, 儲存後馬上生效。
可以留空, 之後想到再加。

創造者問題的固定回覆

同事問「你是誰創造的」「作者是誰」「版權是誰的」這類問題時, 我會直接回下面這句, 不會去問 AI。每個人問的次數一樣會計入每日上限與冷卻。這句是固定答覆, 只供檢視, 不能修改。

機器人人設

填了才算數: 同事問我的年紀、生日、星座、性別、三圍、興趣、婚姻狀態或自我介紹時, 我只會照這裡填的回答; 沒填的欄位我會老實說「這部分我還沒有設定」, 不會自己編。年紀不用填, 我會用出生日自己算。

AI 供應商

三家都填了 Key 也可以, 用哪一家由下面的單選決定。Key 只存在這台電腦的機密存放區, 不會寫進設定檔, 也不會顯示出來 (只看得到末 4 碼)。

機器人定位與範圍

全域的預設設定
各群自己的設定在白名單清單那邊改。
已有本群自訂的群組不會用這份，也不會和本群設定合併。
清空後儲存，會自動回復成出廠預設的角色定位。例：也可以改成「你是華葳集成的資訊小老師，專門陪同事學電腦」這類你想要的身分描述。
清空這個欄位＝不限制範圍，什麼問題都回答。例：也可以改成「離題問題只簡短回答一句，並提醒對方你主要負責電腦學習協助」這類比較寬鬆的寫法。

TypeSafe Jev (選用, 預設停用)

原作者的詐騙分析選項。每次判讀依 TypeSafe 計費; 未填 Key 前不會啟用。

尚未讀取狀態
