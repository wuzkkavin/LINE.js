# AI寶 App 主題色票（定稿）

- 定稿原則：可讀性與對比優先；五套皆為淺色系（員工長時間使用不刺眼）；狀態色保留語意（綠=正常、黃=注意、紅=異常），不隨主題亂改。
- 預設主題：**森林綠**（華葳集成企業色）。
- 對比數值為 WCAG 2.x 相對亮度公式實算（非目測）：一般文字要求 ≥ 4.5:1、按鈕白字 ≥ 4.5:1、狀態圓點等圖形元素 ≥ 3:1。
- 狀態色使用規則（五套通用）：「圓點/圖示色」可較亮；同一狀態若要以小字文字呈現（如「已連線」三字上色），改用「文字版」深色，確保 ≥ 4.5:1。實作上建議狀態文字維持主文字色、只讓圓點上色，最穩妥。

## 通用規則（施工時一併遵守）

1. 焦點框（鍵盤 focus）顏色＝該主題主色，寬度 1.5px。
2. 停用態文字＝次文字降 55% 不透明度；停用按鈕底＝側欄底色。
3. 文字輸入框底色＝卡片底 `#FFFFFF`、邊框＝邊框色、focus 時邊框換主色。
4. 連結文字色＝次要色（黑白主題為主文字加底線），不用點綴色作連結。
5. 狀態圓點與狀態文字分工：圓點可用亮版色；狀態若以文字上色，一律用「文字版」深色。
